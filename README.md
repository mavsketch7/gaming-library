🎮 Game Library

Proyecto frontend desarrollado con HTML, CSS y JavaScript, enfocado en la generación dinámica de contenido a partir de un archivo JSON.

📌 Descripción

Game Library es una aplicación web que muestra un catálogo de videojuegos cargados desde un archivo JSON. La aplicación genera automáticamente:

Página principal con listado de juegos

Sistema de filtrado por categorías y etiquetas

Subpáginas individuales para cada juego

El objetivo principal fue practicar la manipulación del DOM, lectura de datos estructurados y renderizado dinámico de contenido.

⚙️ Funcionalidades

📂 Carga de datos desde archivo JSON

🖥️ Renderizado dinámico del catálogo

🔎 Filtro por categorías

🏷️ Filtro por etiquetas

📄 Generación automática de páginas individuales

📱 Diseño responsive

🧠 Tecnologías utilizadas

HTML5

CSS3

JavaScript (Vanilla)

JSON

🎯 Objetivos de aprendizaje

Comprender cómo estructurar datos en JSON

Manipular el DOM de forma dinámica

Crear filtros interactivos sin recargar la página

Generar contenido reutilizable a partir de una única fuente de datos

Mejorar la organización y escalabilidad del código

🚀 Posibles mejoras futuras
